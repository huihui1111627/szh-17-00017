# 射电望远镜阵列观测控制台

零依赖单页应用，把数十面天线的指向、时间同步、信号质量与地面干扰统一到同一片天空视图中，
并对覆盖范围、成像质量、数据可用性、校准谱系与观测批次进行连续、可溯源、可重算的管理。

## 运行

无需构建。任选一种方式：

```bash
# 方式一：静态服务器（推荐）
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000

# 方式二：直接用浏览器打开 index.html（file:// 也可运行）
open index.html
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 统一到同一片天空视图 | 地平坐标全天空图：方位/高度圈、地形遮挡轮廓、目标轨迹、24 面天线波束、扫描区域覆盖带、地面干扰源同屏对齐 |
| 选择观测目标 | 下拉切换 3C 286 / 3C 147 / 3C 48 / 仙后座 A / 天鹅座 A，基于真实 J2000 星历与台站经纬度实时计算 LST、方位/高度 |
| 排除异常天线 / 调整阵列组合 | 点击右侧天线格单面排除或恢复；“组合”下拉提供全部 / 紧凑核心 / 长基线臂三种预设 |
| 重新设置扫描区域 | 滑块调整扫描半径、按钮偏移中心、直接在天空视图中拖动；调整后覆盖范围与质量立即重算 |
| 连续生成覆盖范围与成像质量变化 | 综合质量指数、L/S/C/X 四频段质量、有效基线数、最长基线、合成波束、相对灵敏度、UV 平面填充、天空覆盖百分比随仿真连续更新 |
| 时间漂移溯源 | 每面天线独立时钟漂移率与偏差累积；越过 12 ns 阈值时标记起点（哪面天线、什么时刻、偏差多少） |
| 目标进入遮挡区 | 360° 地形高度轮廓（北侧山脊）逐方位插值，目标落入地形以下时整片数据标记不可用并记录进入时刻/方位 |
| 干扰源影响多个频段 | 宽带（L/S/C/X）与窄带（L/S）两类注入，按角距 + 天线侧瓣系数逐面逐频段判定，带迟滞防抖 |
| 显示问题从哪里开始 / 哪些数据不可用 | 24 条天线泳道（上下两半分别表示低频段/高频段）+ 4 条频段泳道的分钟级数据可用性时间线；起点处画三角标记；下方列出“起点 ±20 分钟”事件；点击任意时刻定位光标 |
| 校准逐步回退 | 6 步校准谱系（延迟同步 → 带通 → 流量 → 相位 → 指向 → 剔除），可逐步回退；回退延迟校准会恢复原时钟漂移率 |
| 从指定时刻重算 | 时间线点击定位光标后“从此刻重算”，基于事件日志（event sourcing）回放并重仿真后续全部数据 |
| 重启后恢复未完成批次 | 状态每 4 秒写入 localStorage；重启后检测未完成批次，横幅提示，中断时段在时间线以“重启中断”标记，从断点继续 |

## 仿真操作

- 顶部：运行 / 暂停、1×–300× 仿真速度、从此刻重算、重置全部。
- 天线面板：注入时钟漂移、随机排除异常天线、一键恢复。
- 干扰面板：注入宽带 / 窄带地面干扰、清除干扰。
- 调试接口（浏览器 console）：`__ras.fastForward(分钟数)` 可快速推进仿真。

## 代码结构

```
index.html        页面骨架
css/style.css     深色仪表盘样式
js/model.js       天文坐标（GMST/LST/赤道→地平）、波段、地形轮廓、Y 形阵列几何、UV 采样
js/state.js       初始状态、事件溯源、校准/批次/天线事件、localStorage 持久化
js/engine.js      仿真步进、快照（覆盖/质量/可用性）、问题起点检测、时间线采样、重算
js/views.js       天空视图、阵列布局、UV 覆盖、可用性时间线、各侧栏面板渲染
js/app.js         主循环、交互绑定、故障注入、重启恢复
```

## 演示时间线

会话默认从 2026-09-21 07:00 UTC 开始，默认目标天鹅座 A 将于 08:41 前后在西北方向
（方位约 323°）落入地形遮挡区，可在约 1 小时 40 分钟内观察“可见 → 遮挡 → 数据不可用”的完整过程。
切换其他目标可看到不同的升落时刻（各目标星历真实）。
